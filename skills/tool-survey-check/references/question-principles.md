# Принципы формулировок по стадиям ответа

Человек отвечает на вопрос в четыре шага: понимает, вспоминает, выносит суждение, выбирает ответ. Ошибка анкеты ломает один из шагов. Проверяй вопрос по стадиям по порядку.

## 1. Понимание

| Что проверить | Как заметить | Что сделать |
|---|---|---|
| Фразу можно прочитать двумя способами | Вводный оборот в начале, два глагола, к которым можно отнести одно обстоятельство | Перестроить так, чтобы прочтение было одно |
| Сложный синтаксис | Два и более вложенных оборота, вопрос длиннее 25 слов | Разбить на два предложения или два вопроса |
| Многозначное слово | Ключевое слово допускает два разумных значения: «счёт», «заказ», «подписка» | Уточнить, какое значение имеется в виду |
| Расплывчатое понятие | «Проблемы», «удобный», «активный» несут главный смысл | Дать определение или заменить наблюдаемым событием |
| Расплывчатая частота | «Часто», «редко», «иногда», «много» в вопросе или вариантах | Числа или явные интервалы |
| Скрытое допущение | «Ваш последний платёж», «улучшенный дизайн», «снова» | Вопрос-фильтр перед основным |
| «Обычно», «как правило» | Спрашиваем про поведение, а устойчивой привычки может не быть | Спросить про последний случай или про конкретный период |
| Несколько событий в одном вопросе | «Переводили, оплачивали или пополняли» | Серия простых вопросов |
| Незнакомый термин | Название функции или отраслевое слово | Короткое определение прямо в вопросе. Иначе получишь ложные «нет» |
| Спорное утверждение как причина | «X происходит, потому что Y — согласны?» | Убрать причину или спросить о ней отдельно |
| Тема может быть незнакома | Вопрос требует специальных знаний | Фильтр на знакомство или вариант «не знаю» |
| Два почти одинаковых вопроса рядом | Различаются одним словом | Оставить один |

## 2. Вспоминание

| Что проверить | Что сделать |
|---|---|
| Свойство меняется со временем: адрес, доход, тариф | Указать, на какой момент спрашиваем |
| Период не соответствует частоте события | Чем чаще и мельче событие, тем короче период. Редкое и значимое — длиннее |
| Спрашиваем о действиях других людей | Не спрашивать, если можно опросить их самих |
| «Когда вы последний раз…» про рутинное | Люди не хранят рутину как «последний раз». Спросить про короткий период |
| Детали одного эпизода из множества похожих | Спросить частоту или сузить период |
| Подсказка для памяти | Подсказывать, что произошло, потом кто и где. Когда — слабая подсказка. Лучше несколько подсказок сразу |
| Длинный период | Привязать начало к личному событию, а не к дате |
| Сумма по частым событиям | Разбить на подвопросы по видам, каналам, ситуациям |
| Ожидаемое число событий больше десяти | Человек будет прикидывать, а не считать. Сократить период или честно просить оценку |
| Точные даты рутинных событий | Не требовать: их восстанавливают, а не помнят |
| Длительность с перерывами | Уточнить, считать ли паузы |
| Нужна длительность состояния | Спросить длительность прямо, а не вычислять из двух дат |
| Круглые числа в ответах: 5, 7, 30 | Ожидать округление и не читать его как точность |
| Важен точный ответ | Сказать, что вопрос важен и можно не торопиться |

## 3. Суждение

| Что проверить | Что сделать |
|---|---|
| Варианты частоты сами подсказывают «норму» | Не давать диапазоны, скошенные в одну сторону. Лучше открытое числовое поле с коротким периодом |
| В тексте вопроса упомянута норма или среднее | Убрать: человек подстроит ответ под названное число |
| Частота в процентах | Не просить: человек переключается с памяти на впечатление |
| Нагруженные слова | Убрать слова, которые включают ценности вместо предмета вопроса |
| Узкий вопрос подменяется общим принципом | Сформулировать про конкретную меру, без отсылок к «справедливости» и «заботе» |
| Общий принцип и конкретный случай | Не выводить одно из другого. Спрашивать отдельно |
| «Почему вы так считаете?» перед оценкой | Сначала оценка, потом причины |
| Смешанное отношение | Дать возможность ответить «и да, и нет» или мерить плюсы и минусы отдельно |
| Оценка сразу по многим сторонам | Человек держит в голове одно-два соображения. Разбить по сторонам |
| Экстремальный пример для сравнения | Не ставить рядом самый дорогой или самый дешёвый вариант, если нужна абсолютная оценка |
| Вопрос о причине | Понятно ли, с чем сравнивается событие? Смена подлежащего меняет ответ |
| Два зеркальных вопроса подряд про «наше» и «чужое» | Человек выровняет ответы ради справедливости. Разнести, если это не цель |
| Социально желательный ответ | Нормализующее вступление: «Одни делают так, другие иначе…» |
| Социально одобряемое поведение | Добавить косвенный проверочный вопрос |

## 4. Ответ

| Что проверить | Что сделать |
|---|---|
| Число точек шкалы | Около семи. Две-три не различают людей, одиннадцать и больше ненадёжны |
| Подписи | Подписать все точки, а не только края |
| Однополярная шкала | От нуля или единицы вверх. Без отрицательных чисел |
| Ноль на оценочной шкале | Не использовать, если он читается как «признака нет совсем» |
| Сложная оценка | Два шага вместо длинной шкалы: сначала грубо, потом уточнение |
| Крайний вариант обрезает хвост | Если хвост важен — открытое поле |
| Неизвестная человеку величина | Разрешить ответить диапазоном |
| Закрытый список | Его читают как полный. Проверить, что нет пропущенных вариантов, добавить «другое» с полем |
| «Отметьте всё, что подходит» | Занижает число отметок. Если важна полнота — да или нет по каждому пункту |
| Порядок вариантов | На экране выигрывают первые, на слух — последние. Случайный порядок, в том числе для двух вариантов |
| «Нет мнения», «не относится ко мне» | Выписывать явным вариантом |
| Вероятность | Мельче шаг у краёв шкалы. Вопросы о событии и его противоположности ставить рядом |

## Чувствительные темы

- Проверь три вещи: давит ли желательность, вторгаемся ли в личное, есть ли риск последствий от раскрытия.
- Доход спрашивай интервалами.
- Чувствительное ставь после нейтральных блоков и давай вариант «предпочитаю не отвечать».
- Обещание конфиденциальности само смещение не исправит. К нейтральным вопросам его не добавляй: оно настораживает.
- Для порицаемого поведения недавний период может давать большее занижение, чем длинный.
- Чувствительность оценивай не «в среднем», а для тех, кого тема задевает сильнее.
