# Виды опросов

Сначала определи вид, потом собирай блоки. У каждого вида свои ограничения: если задача в них не укладывается, вид выбран неверно.

## Как выбрать

1. Продукта ещё нет, есть описание идеи → проверка концепции. Идей много → приоритизация функций.
2. Продукт есть, нужно понять категорию и людей в ней → привычки и использование.
3. Продукт есть, нужно выбрать, что улучшать → приоритизация функций.
4. Беспокоит конкретное взаимодействие → удовлетворённость после действия.
5. Человек только что пришёл → опыт первых шагов. Только что ушёл → причины ухода.
6. Нужно регулярно мерить отношение в целом → готовность рекомендовать. Положение среди конкурентов → здоровье бренда.
7. Выбор между вариантами: названия → тест названий; реклама и тексты → тест сообщений; цена → ценовой опрос.
8. Нужно разделить людей на группы по потребностям → сегментация. Сначала проверь, не решается ли это данными компании.

## Виды

| Вид | Когда брать | Когда не брать | Типовая последовательность |
|---|---|---|---|
| Проверка концепции | Есть короткое описание идеи, разработка не начата | Идеи ещё нет; нужно предсказать продажи: заявленное намерение завышает спрос | Скринер → поведение в категории → показ описания → понял ли → интерес и намерение → сомнения → демография |
| Привычки и использование | Входим в категорию или нет общей картины | Ответ лежит в своих данных; нужна причина одного конкретного провала | Скринер → что и как часто используют → критерии выбора → барьеры → отношение → демография |
| Удовлетворённость после действия | Есть конкретная точка контакта, меряем регулярно | Нужно отношение к продукту в целом; событие было давно | 3–7 вопросов сразу после события: оценка → усилия → причина оценки открытым вопросом |
| Готовность рекомендовать | Регулярный замер лояльности к продукту в целом | Оценка одного действия; разовое решение о функции | Вопрос о рекомендации → причина → оценки по сторонам → демография |
| Ценовой опрос | Нужен приемлемый диапазон цены до запуска или изменения | Нет понятного людям описания продукта; цена уже в продаже и есть данные | Описание продукта → вопросы о цене: четыре порога, если диапазон неизвестен; ступени, если известен |
| Тест названий | Есть 3–7 вариантов | Вариант один: без сравнения результат не читается | Показ вариантов в случайном порядке → ассоциации → понятность → запоминаемость → выбор |
| Тест сообщений и рекламы | Есть готовые материалы до запуска | Материалов нет; нужен эффект на продажи: это эксперимент | Показ → что запомнил → главное сообщение своими словами → оценки → намерение |
| Сегментация | Нужны группы по потребностям и установкам для разной работы с ними | Группы выделяются по данным о поведении; выборка мала | Поведение → потребности и установки таблицей утверждений → демография |
| Здоровье бренда | Регулярный замер знания, рассмотрения, использования среди конкурентов | Разовый вопрос о функции | Знание без подсказки → с подсказкой → рассмотрение → использование → образ → рекомендация |
| Опыт первых шагов | Новые пользователи, недавний первый опыт | Прошло много времени: детали забыты | Что ожидал → как прошло по шагам → где застрял → что удивило |
| Причины ухода | Человек фактически ушёл | Уход только предполагается: это другая аудитория | Подтверждение факта → главная причина открыто → причины списком → куда ушёл → что вернуло бы |
| Приоритизация функций | Длинный список функций, ресурсов мало | Функций две-три; люди не понимают, что это за функции | Скринер → задания на выбор лучшего и худшего из набора либо оценка «есть / нет» по каждой функции |

## Правила сборки

- Скринер короткий, целевой ответ не подсвечен.
- Показываемые материалы и варианты — в случайном порядке.
- После показа концепции сначала проверь, что человек её понял, и только потом спрашивай об интересе.
- Простое «оцените важность каждой функции» даёт «всё важно». Для приоритизации нужен вынужденный выбор.
- Вопрос о причине оценки — открытый и сразу после оценки.
- Заявленное намерение не равно спросу. Пиши это в выводах прямо.
