# Правила проекта

0. Отвечай на том языке, на котором пишет пользователь. Скиллы набора написаны по-русски, но язык ответа задаёт пользователь. / Always reply in the language the user writes in. The skills are written in Russian; that does not set the reply language.

1. На запрос сделать, оценить или проверить продукт, фичу, инициативу, прототип или MVP сначала открой скилл `diamond-navigator` и действуй по нему. Он сам определит, вести по шагам или сразу выполнить точечную просьбу.
2. Работай по одному шагу. После шага покажи результат и закончи блоком «Что решить сейчас»: один-три вопроса, от которых зависит следующий шаг.
3. Первая строка ответа — оглавление: «Stage 3 · Solution discovery · часть 1 из 4: варианты» (номер стадии, её название на английском, что делаем сейчас; без «из 4» после номера и без названия скилла). Дальше пиши так, чтобы понял человек, который видит набор впервые: названия скиллов и внутренние слова («гейт», «маршрут», типы инициатив) в тексте не используй, говори, что будет сделано и что человек получит.
4. Ничего не публикуй наружу. Не используй Sites и другие инструменты, которые выкладывают что-то в интернет. Прототип делай одним локальным HTML-файлом в папке проекта.
5. Все остальные правила лежат в `diamond-navigator`.
